# ChatViz - WhatsApp Chat Analyzer

A web application for analyzing and visualizing WhatsApp chat data to gain insights into messaging patterns, media sharing, and more. Built using Python and Streamlit, this tool provides interactive charts and graphs to help you understand your chat data.
## Features

- **Top Statistics :** Displays total messages, words, media shared, and links shared.
- **Monthly & Daily Timelines :** Visualizes message trends over months and days.
- **Activity Maps :** Shows the most active days and months for messaging.
- **Word Clouds :** Generates word clouds to highlight frequently used words.
- **Most Common Words :** Lists and visualizes the most common words in chats.
- **Emoji Analysis :** Analyzes and visualizes emoji usage in chats

## Technologies Used

  - **Programming Language :** Python
  - **Libraries :** Streamlit, Pandas, NumPy, Matplotlib, Seaborn, Plotly, WordCloud, NLTK

### Steps

1. Clone the repository :
```
   git clone https://github.com/YourUsername/whatsapp-chat-analyzer.git
```

2. Navigate to the project directory :
```
  cd whatsapp-chat-analyzer
```

3. Create a virtual environment : 
```
  python -m venv venv
```

4. Activate the virtual environment :
```
  venv\Scripts\activate
```

5. Install the required dependencies :
```
  pip install -r requirements.txt
```

6. Run the Streamlit app :
```
  streamlit run app.py
```
